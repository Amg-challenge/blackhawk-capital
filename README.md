# Black Hawk Capital

An institutional revision of the existing AMC 2026 student-project website.
The six original alpine photographs and their credits are retained. The supplied
official logo is used without altering its pixels.

## Files

- `index.html`: page structure and base visual theme.
- `assets/institutional.css`: typography, navigation, spacing and responsive layout.
- `assets/content.js`: team, document links, allocation figures and live results.
- `assets/site.js`: navigation, research tabs and scroll-triggered landscape changes.
- `asset_sources.json`: original photograph URLs and asset fingerprints.

Open `index.html` in a browser to view the website locally. It is also ready for
the repository's existing GitHub Pages configuration (`main`, root directory).

The current allocation is provisional. Research documents with empty URLs are
clearly labeled as drafts, planned or awaiting publication. Add a verified URL in
`assets/content.js` when the corresponding file is published. Live performance
fields remain empty until Bloomberg observations are available.

## Google Sites requirement

The AMC general guidelines require the fund website to use Google Sites. This
source revision updates the visual base; it does not create or publish a Google
Site. The group still needs a site in its own Google account. The text, logo and
photographs can be reused in native Google Sites sections. Google Sites also
supports full-page website embeds; the group's final Google Sites URL and its
embedded documents must be tested with viewer access before submission.

Official guidance: https://support.google.com/sites/answer/90569?hl=en
